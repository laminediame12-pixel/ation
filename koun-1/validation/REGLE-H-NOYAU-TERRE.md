# H-NOYAU-TERRE — règle formalisée par le propriétaire (2026-11-25)

Sous-règle de lecture d'équilibre, en observation. Elle ne décide pas seule la victoire.

## Définitions
- **Noyau Terre** : les quatre figures dont Feu et Air sont saturés (vérifié : 4, 8, 12, 16).
  | Figure | N° | Miroir | Caractère Terre |
  |---|---|---|---|
  | Albus | 4 | Fortuna Major (12) | Terre saturée, Eau active |
  | Tristitia | 8 | Populus (16) | seul Terre ouvert |
  | Fortuna Major | 12 | Albus (4) | Terre et Eau ouvertes |
  | Populus | 16 | Tristitia (8) | Terre saturée (équilibre total) |
- **Triplet mobile** (déplacement +6 de R1 / R7) : Amissio (6), Carcer (10), Puella (14) ; sa résolution naturelle aboutit dans le noyau.

## Lecture
1. **Phase** : figures diagnostiques (R1, R7, nœuds) majoritairement dans le triplet mobile → *mobile*, équilibre non tranché ;
   majoritairement dans le noyau → *phase d'équilibre*.
2. **Qualité de l'équilibre** : Tristitia dominante = en suspens ; Populus = concrétisé ; Albus = stable, Eau encore active ;
   Fortuna Major = plus sec (Terre et Eau ouvertes).
3. **Articulation** : filtre d'équilibre ; en lecture serrée, Populus renforce la stabilité, Tristitia seule maintient l'ouverture.
4. **Nul** : non tranché tant que le thème reste mobile ; plus lisible quand Populus (ou Tristitia → Populus) s'impose dans les nœuds.

Texte de verdict :
```
Équilibre (H-NOYAU-TERRE) :
– Mobile : dominance Amissio / Carcer / Puella
– Équilibre en suspens : Tristitia dominante dans le noyau
– Équilibre concrétisé : Populus (ou résolution Tristitia → Populus)
– Variantes stables : Albus / Fortuna Major
Règle en observation.
```

## Repères vérifiés sur les 106 matchs connus (22 nuls, 21 %)
- **Lecture de la page (Koun-35)**, sur toutes les bases et résultantes : mobile 2 nuls sur 24 (8 %) ; concrétisé 5/16 ; stable Albus 8/28 ;
  stable Fortuna Major 3/19 ; suspens 4/19. C'est la phase mobile qui écarte le nul ; elle est l'un des six signes de la convergence du nul (v3).
- **Lecture formalisée**, sur les figures diagnostiques (R1, R7 et résultantes des nœuds diagonaux des deux pôles ; `outils/noyau_terre_formel.js`) :
  mobile 4/22 (18 %) ; concrétisé (Populus) 4/28 (14 %) ; suspens 5/19 ; sec (Fortuna Major) 6/27 ; stable (Albus) 3/8. Sur ces seules figures,
  la phase ne sépare pas le nul, et Populus concrétisé n'annonce pas plus de nuls.
- Thème 12-10-14-5 (nul validé) : mobile dans les deux lectures (7 mobiles contre 6 noyau sur tout le thème).
